# Max Seg & Max Saúde — contexto para agentes

Base atual de desenvolvimento: feature/affiliate-single-registration.

Projeto: aplicativo Expo/React Native com suporte web/PWA, API/servidor e recursos de afiliados.

Regras:
1. Preserve a branch base e não faça merge automático.
2. Crie uma branch própria para mudanças e entregue um Pull Request.
3. Não substitua o código atual por ZIPs antigos.
4. Preserve a implementação de afiliados existente.
5. Nunca versionar segredos ou credenciais.
6. Verifique package.json, app.config.ts e eas.json antes de mudanças de build.
7. A configuração EAS usa EXPO_PROJECT_ID em runtime; o Project ID real não deve ser inventado.
8. Não declarar build EAS concluída sem execução real.
9. Execute as validações apropriadas antes de abrir o Pull Request.
10. Explique mudanças importantes em português.
